SIINCOMA (Sistema de Información para el Control de Mascotas) es una aplicación web que centraliza la información de las mascotas de un conjunto residencial y de sus tutores. Permite registrar a cada mascota con su fotografía y su estado sanitario, generar alertas de extravío, mudanza y vacunación, y consultar reportes para la toma de decisiones. Su enfoque es social y preventivo: busca promover la tenencia responsable y evitar el abandono, no sancionar a los residentes.
